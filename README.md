# Cadastro de Livros

Aplicação desktop desenvolvida em Python e PySide6 para cadastro e consulta de livros de uma pequena biblioteca.

## Funcionalidades

- Cadastro de título, autor, ano e ISBN;
- Validação dos campos obrigatórios;
- Exibição dos livros em tabela;
- Pesquisa por título ou autor;
- Seleção de registros;
- Limpeza do formulário;
- Dados armazenados em memória durante a execução.

Os botões de atualização e exclusão estão desabilitados porque essas funcionalidades serão adicionadas posteriormente.
